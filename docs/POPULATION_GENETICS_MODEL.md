# Phase 6.1 — Explicit population genetics

TRISOLARIS now tracks allele frequencies rather than only trait indices.

The first population-genetics model includes four abstract biallelic loci linked
to the same physiological domains used by the lineage layer:

- thermal resilience
- water conservation
- oxygen efficiency
- dietary flexibility

## Processes

The model includes:

- founder-frequency shifts
- directional selection
- symmetric mutation
- migration toward connected population means
- drift scaled by effective population size

## Outputs

For every refuge population TRISOLARIS reports:

- allele frequencies
- heterozygosity
- gene-flow proxy
- isolation potential

Across populations it reports a simple FST-like differentiation proxy.

## Conservative interpretation

A high FST-like value is not a species declaration.

TRISOLARIS still requires explicit reproductive isolation, persistent history,
developmental plausibility and later genomic models before any taxonomic label
can be considered.
