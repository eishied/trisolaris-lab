# Phase 11.0 — Research Releases

Phase 11 turns committed simulation outputs into an auditable research object.

A release manifest records:

- release and experiment IDs;
- Git commit;
- dataset paths and model versions;
- epistemic levels;
- random seeds;
- limitations;
- evidence-ledger entries;
- model-conditional claims;
- reproducibility checks.

## Publication gate

The automated system may mark a package as **RESEARCH_NOTE** when the internal
reproducibility checks pass.

It must not automatically mark a package as **ARXIV_READY**, **SUBMITTED** or
**PUBLISHED**. Those states require deliberate human scientific review.

## Evidence ledger

Observed, literature, modeled, derived and speculative evidence remain
distinguishable. In particular, H-01 remains explicitly speculative even when
downstream models are reproducible.

## Claims

Claims generated by this layer are narrow and qualified. Ensemble frequencies
are reported as frequencies under the declared model and perturbation envelope,
never as real-world probabilities.

## Reproducibility

The release stores the Git commit, model identifiers, dataset paths and replay
seeds so a research note can be rebuilt from the same repository state.
