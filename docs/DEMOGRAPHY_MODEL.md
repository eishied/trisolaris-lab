# Phase 7.1 — Time playback, demographic shocks and recovery

The planetary-history layer now has a time-dependent demographic scaffold.

## Population index

TRISOLARIS does not pretend to know future census numbers.

Instead it uses a normalized **population index** and a modeled carrying-capacity
index for each named population region.

The index can:

- expand toward carrying capacity,
- fall after an explicit disturbance,
- enter a bottleneck,
- recover according to environmental and technological resilience.

## Disturbances

Disturbances are never inserted automatically.

The user can explore:

- drought
- cold event
- food crisis
- infrastructure failure

Severity is a scenario parameter.

## Recovery

Recovery potential depends on:

- knowledge continuity,
- mobility,
- infrastructure,
- open and controlled agriculture.

This is a systems-resilience proxy, not a judgment about a society.

## Playback

The public interface can replay the history from year 0 to the current
evolutionary horizon. The underlying lineage/evolution clock remains the master
time horizon; playback only changes which historical slice is being viewed.
