# Phase 5.1 — Refugia and migration network

TRISOLARIS now converts regional settlement support into named **refugia**.

These are geographic population zones, not ethnic groups, subspecies or species.

## How refugia are created

Contiguous latitude bands above the assisted-settlement threshold are grouped
into regions. Each region receives:

- a neutral geographic name,
- center latitude and span,
- natural and assisted support,
- agriculture potential,
- technology dependency,
- relative capacity weight.

## Migration

Pairwise migration potential depends on:

- user-controlled mobility,
- latitudinal separation,
- environmental support at both refugia.

The result is a network of potential movement corridors.

## Isolation

Isolation is a geographic/demographic precursor only.

A high isolation potential does **not** automatically mean:

- genetic divergence,
- a new subspecies,
- a new species,
- a new culture.

Those require explicit time, generations, inheritance, selection, drift, gene
flow and historical processes in later phases.

## Why names appear now

The user needs to distinguish populations through time. Names are therefore
assigned at the **regional population** level first. Later lineage names will
be created only when a modeled historical branching event occurs.
