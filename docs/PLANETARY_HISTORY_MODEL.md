# Phase 7.0 — Planetary footprint and population history

TRISOLARIS now links the biological lineage model to a first human planetary
history layer.

## What is represented

Each viable named population can now develop modelled values for:

- settlement intensity
- settlement pattern
- open agriculture
- controlled-environment agriculture
- infrastructure
- water recycling
- thermal shelter
- mobility network
- knowledge continuity
- cultural differentiation proxy
- anthropogenic footprint proxy

Migration links are inherited from the refugia network and adjusted by
mobility and settlement intensity.

## Important interpretation

This is not a deterministic theory of civilization.

Technology is a functional environmental-buffering variable. Higher values do
not imply a better society.

Knowledge continuity describes storage, transmission and institutional
persistence. It is not intelligence.

Cultural differentiation describes separation between populations under
isolation and reduced contact. It is not a ranking of cultures.

## Geography

The scientific model currently resolves latitude bands. Longitude is not yet a
physical state variable.

The public globe therefore uses longitude only as a diagrammatic placement so
that users can visually distinguish populations. The interface labels that
limitation explicitly.
