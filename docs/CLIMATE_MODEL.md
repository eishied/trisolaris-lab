# Phase 3.0 — Regional climate begins

TRISOLARIS must never imply that an entire planet has one temperature.

The first climate engine is therefore a **1-D latitudinal energy-balance model (EBM)**. It resolves latitude bands and approximates:

- annual-mean stellar energy by latitude,
- planetary albedo,
- linearized outgoing longwave radiation,
- meridional heat transport,
- an Earth-referenced greenhouse offset.

## What this model is useful for

It can answer questions such as:

- Can the equator and poles occupy different thermal regimes?
- Does a planet that looks acceptable globally still contain hostile regions?
- Do thermally plausible refuge bands appear?
- How do distance, albedo and greenhouse assumptions move those bands?

## What it cannot answer

It is not a GCM.

It does not yet resolve:

- longitude,
- continents,
- topography,
- ocean currents,
- cloud feedback,
- seasons,
- storms,
- atmospheric chemistry,
- pressure,
- salinity,
- ice-sheet dynamics.

Therefore outputs are labeled **MODELED** and any “liquid-water” measure is only a **thermal proxy**.

The next climate upgrade will add seasonal/longitudinal structure and eventually connect a validated climate model to the biosphere and human-physiology layers.
