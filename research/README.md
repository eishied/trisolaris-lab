# Research workspace

Research objects should move through explicit states:

`question → hypothesis → experiment → finding → evidence review → publication candidate`

Planned subdirectories:
- `questions/`
- `hypotheses/`
- `evidence/`
- `findings/`
- `research-log/`

Stable IDs should be used from the beginning (for example `RQ-0001`, `HYP-0001`, `EXP-000001`, `FIND-0001`).
