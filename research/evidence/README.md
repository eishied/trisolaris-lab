# Evidence Ledger

Each scientific claim should receive a stable ID such as `CLAIM-0001`.

Recommended record:

```yaml
claim_id: CLAIM-0001
claim: "..."
status: candidate
support:
  experiments: []
  datasets: []
literature: []
confidence: low
alternative_explanations: []
limitations: []
publication_links: []
```

A claim can only advance when its evidence and limitations are explicit.
