# Publications

This directory contains the research-publication lifecycle for TRISOLARIS LAB.

## Structure

- `ideas/` — candidate questions and paper concepts.
- `research-notes/` — early evidence summaries.
- `working-papers/` — manuscripts with reproducible experiment support.
- `submitted/` — submitted manuscripts.
- `published/` — accepted/published work.
- `templates/arxiv/` — Markdown/metadata templates for arXiv-ready builds.

## Principle

A manuscript is an output of the evidence system, not a replacement for it.

Every quantitative statement should be traceable to experiment IDs, dataset snapshots and a Git commit.
